Setup guide · Nov 3, 2026

Getting the keys for Trend Radar

Ordered by urgency. Each key says what it's for, what it costs, the steps, which .env lines it fills, and a command to check it works. Menu labels on these sites change sometimes; if one doesn't match exactly, look for the closest equivalent.

Keys go in .env only. That's the file in the project root, which is gitignored; .env.example lists every name. Never paste keys into chat, a commit or a screenshot. When you're done, tell me "keys are in" and I'll test them without displaying them.

A · Do today: free, and starts real data flowing

YouTube history can't be filled in later, so every hour without the key is data we lose.

1. YouTube Data API key Free10 min Discovers new GTA 6 videos and snapshots their views every hour. This is our main signal.
  1. Go to Google Cloud → New project. Name it trend-radar → Create, then make sure it's selected in the top bar.
  2. Open YouTube Data API v3 → Enable.
  3. Go to APIs & Services → Credentials → Create credentials → API key.
  4. Click the new key → API restrictions → Restrict key → tick only YouTube Data API v3 → Save.
  5. Leave Application restrictions at None for now. Once the server exists we'll restrict it to the server's IP.
.envYOUTUBE_API_KEY=AIza…
Test (costs 1 of 10,000 daily units)
set -a; source .env; set +a
curl -s -H "X-Goog-Api-Key: $YOUTUBE_API_KEY" \
  "https://www.googleapis.com/youtube/v3/videos?part=statistics&id=dQw4w9WgXcQ" | head -20

No billing account is needed; the free quota is 10,000 units a day. A quota increase requires a Google audit that takes weeks, so don't apply now.

2. Twitch application Free10 min Live viewers on GTA 6 streams and the top clips of the day.
  1. Log in to Twitch and turn on two-factor authentication (Settings → Security). Twitch won't let you register apps without it.
  2. Go to dev.twitch.tv → Console → Applications → Register Your Application.
  3. Fill in: Name trend-radar-<something unique> (it can't contain "Twitch"), OAuth Redirect URL http://localhost (required but unused), Category Analytics Tool, Client Type Confidential → Create.
  4. Click Manage → copy the Client ID → click New Secret → copy the secret. It's shown once.
.envTWITCH_CLIENT_ID=…
TWITCH_CLIENT_SECRET=…
Test: should print the "Grand Theft Auto VI" category
set -a; source .env; set +a
TOKEN=$(curl -s -X POST https://id.twitch.tv/oauth2/token \
  -d client_id="$TWITCH_CLIENT_ID" -d client_secret="$TWITCH_CLIENT_SECRET" -d grant_type=client_credentials \
  | python3 -c 'import sys,json; print(json.load(sys.stdin)["access_token"])')
curl -s -H "Client-Id: $TWITCH_CLIENT_ID" -H "Authorization: Bearer $TOKEN" \
  "https://api.twitch.tv/helix/games?name=Grand%20Theft%20Auto%20VI"

No user permissions (scopes) are needed. We only read public streams and clips with an app token.

3. Telegram bot + public channel Free10 min Spike alerts go to a public channel, and failure alerts come privately to you.
  1. In Telegram, open @BotFather → send /newbot → give it a name, then a username ending in bot. Copy the token it replies with.
  2. Create a New Channel → make it Public → choose a link like t.me/your_channel.
  3. Channel → Administrators → Add Admin → search your bot → allow only Post messages.
  4. For your private ops chat: open your bot, press Start, send it "hi". Then open https://api.telegram.org/bot<TOKEN>/getUpdates in your browser and copy the number at "chat":{"id": …}.
.envTELEGRAM_BOT_TOKEN=123456:ABC…
TELEGRAM_CHANNEL_ID=@your_channel
TELEGRAM_OPS_CHAT_ID=123456789
Test: you should get a message from your bot
set -a; source .env; set +a
curl -s "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/sendMessage" \
  -d chat_id="$TELEGRAM_OPS_CHAT_ID" -d text="Trend Radar test ✅" | head -c 200

Don't put "GTA" in the channel name, for the same trademark reason as the domain.

B · Submit today: approvals take days or weeks

These are for sources we add after launch. Applying now means approval might arrive in time.

4. Reddit Data API (commercial use) Free to applySlow What people are saying in GTA subreddits. Commercial use needs Reddit's approval.
  1. Read the Reddit Data API wiki. It links to the current access request process.
  2. Open Reddit Help → Submit a request and choose the API / developer access option.
  3. Describe it plainly: "Read-only access to public posts in GTA-related subreddits. We compute aggregated topic trends for video creators. We don't resell or display raw Reddit content, and we follow your rate limits and data deletion rules." Mention that a paid tier is planned (that's what makes it commercial).

No .env lines yet; they'll be added when the connector is built (P8.4).

5. Google Trends API (alpha) Free to applyNot guaranteed Search interest, an extra WATCH signal. Access is by application only.
  1. Open Google Trends API → apply for alpha access.
  2. Use the same Google account as the YouTube project, and describe the use case the same way as for Reddit.

If it's never granted, nothing breaks; it's optional.

6. Threads API (keyword search) FreeApp review Posts mentioning GTA 6 on Threads. Keyword search needs Meta's app review.
  1. Go to Meta for Developers → My Apps → Create app → pick the use case Access the Threads API.
  2. Under permissions, add threads_basic and threads_keyword_search.
  3. Create the app today. Submit it for App Review once the site is live, because the review asks for a public privacy policy URL (that comes in P4.5).

Check Meta's docs for the current keyword search rate limit before we build this connector.

C · Costs money: needed for the server

These unblock Phase 1 (P1.1–P1.3). About €5/month plus about $10/year.

7. VPS (Hetzner recommended) ~€5/mo15 min The server that runs everything. Hetzner costs about a quarter of DigitalOcean for the same specs.
  1. If you don't have an SSH key yet, create one on your Mac: ssh-keygen -t ed25519, then copy it with pbcopy < ~/.ssh/id_ed25519.pub.
  2. Sign up at Hetzner Cloud (they verify your identity, sometimes with a small deposit) → New project trend-radar.
  3. Add Server: Location Ashburn (US East, closest to most creators) or an EU site; Image Ubuntu 24.04; Type the smallest shared x86 plan with 4 GB RAM (CX22 or its current equivalent).
  4. SSH keys: paste your public key. Firewalls: create one allowing inbound TCP 22, 80, 443 only.
  5. Create the server → copy its IPv4 address and send it to me. It's not a secret.
Test
ssh root@<SERVER_IP> 'uname -a'

Don't install anything on it. Ansible will configure it (P1.2), including turning off root and password login.

8. Domain on Cloudflare ~$10/yr10 min The site's address, with DNS and HTTPS. Cloudflare Registrar sells domains at cost.
  1. Pick a name without "GTA". Take-Two sends takedowns over trademarks in domains. Something like trendradar.gg or creatorradar.io.
  2. Go to Cloudflare dashboard → Domain Registration → Register Domains → buy it. If you already own a domain elsewhere, use Add a domain instead and switch its nameservers to Cloudflare.
  3. Once the VPS exists: DNS → Add record: type A, name @, IPv4 = server IP, proxy off (DNS only, grey cloud) so Caddy can get its HTTPS certificate. Add the same record with name www.
.envDOMAIN=yourdomain.com
Test: should print the server IP
dig +short yourdomain.com
9. Cloudflare R2 bucket + access key Free tier10 min Nightly database backups, kept for 14 days. The free tier is 10 GB; a card is required to enable R2.
  1. Cloudflare dashboard → R2 Object Storage → enable it (asks for a payment method; you won't be charged within the free tier).
  2. Create bucket → name trend-radar-backups → default location.
  3. Bucket → Settings → Object lifecycle rules → Add rule: apply to all objects, delete after 14 days.
  4. Back in R2 → Manage API tokens → Create API token: permission Object Read & Write, Specific bucket = trend-radar-backups only → Create.
  5. Copy the Access Key ID and Secret Access Key (shown once), plus your Account ID (on the R2 overview page, and in the endpoint URL https://<ACCOUNT_ID>.r2.cloudflarestorage.com).
.envR2_ACCOUNT_ID=…
R2_ACCESS_KEY_ID=…
R2_SECRET_ACCESS_KEY=…
R2_BACKUP_BUCKET=trend-radar-backups

D · Once the domain exists

Needed in Phases 2, 4 and 5. Resend needs the domain; the rest can be done anytime.

10. Resend (email) Free tier15 min The daily digest email to waitlist subscribers. The free tier covers 3,000 emails a month.
  1. Sign up at resend.com → Domains → Add domain. Use a subdomain like mail.yourdomain.com, which keeps email reputation separate.
  2. Add the DNS records it shows (SPF, DKIM, MX) in Cloudflare. Resend can add them automatically if you connect Cloudflare. Wait for Verified.
  3. API Keys → Create API key: permission Sending access, domain = your domain only → copy it (shown once).
.envRESEND_API_KEY=re_…
EMAIL_FROM="Trend Radar <digest@mail.yourdomain.com>"
11. Sentry (error tracking) Free10 min Sends you every crash in the worker, API or website, with a stack trace.
  1. Sign up at sentry.io (Developer plan, free).
  2. Create three projects: trend-radar-worker (Python), trend-radar-api (FastAPI), trend-radar-web (Next.js).
  3. For each: Project Settings → Client Keys (DSN) → copy the DSN.
.envSENTRY_DSN_WORKER=https://…
SENTRY_DSN_API=https://…
NEXT_PUBLIC_SENTRY_DSN=https://…
12. Healthchecks.io (dead worker alarm) Free5 min The worker pings it every run. If the pings stop (crash, server down), you get a Telegram alert.
  1. Sign up at healthchecks.io → Add Check → name worker, Period 1 hour, Grace 30 minutes.
  2. Copy the ping URL (https://hc-ping.com/…).
  3. Integrations → Telegram → follow the steps to connect your Telegram account.
.envHEALTHCHECKS_PING_URL=https://hc-ping.com/…
13. GitHub token (server pulls images) Free3 min The repo is private, so its Docker images are too. The server needs a read-only token to pull them.
  1. Go to GitHub → Settings → Developer settings → Tokens (classic) → Generate new token. The container registry needs a classic token.
  2. Note: trend-radar server pull. Expiration: 1 year (set a calendar reminder; deploys break when it expires).
  3. Scope: tick only read:packages → Generate → copy.

14. UptimeRobot (site down alarm) Free5 min Checks the site from outside every 5 minutes. A monitor on our own server couldn't report the server itself being down.
  1. Wait until the site is live (after P1.3).
  2. Sign up at uptimerobot.com → New monitor → HTTP(s) → URL https://yourdomain.com/api/health → 5-minute interval.
  3. Add your email and Telegram as alert contacts.

No .env lines; it runs outside our system.
