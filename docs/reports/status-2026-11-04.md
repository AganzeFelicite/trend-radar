| Plan | What happened | Why |
|---|---|---|

| Phase 2 safety basics (backups, CI/CD, Sentry) before Phase 3 | Skipped ahead to Phases 3–4; safety basics not started | Nothing to deploy to or back up to without a server |
| Launch sources: YouTube + Twitch (Nov 3 decision) | Bluesky and News RSS added before launch | Owner decision Nov 4: all sources first. Twitch has no GTA VI category yet, so YouTube alone was too thin |
| Keyword topics v1; embeddings only if the top-20 review shows misses | Upgrade path taken: multilingual MiniLM embeddings (fastembed/ONNX, no torch) in pgvector, HDBSCAN, Claude Haiku 5.5 naming, merging and spam flags. Curated aliases kept (hybrid) | Owner at the top-20 review on Nov 4: "we need some sort of AI". Estimated ~$2–6/month, owner approved. 27.6K tokens used so far, including re-runs while tuning |
| Plain SQL views for silver → gold | dbt Core | Owner decision Nov 4; brief updated |
| Wikipedia article → topic mapping in P3.2 | Collected but not mapped to topics | Not done yet. The site therefore says "3 sources" |
| Local ports 3000 | Web on 3100 | Port 3000 is used by another project on the Mac |

### Known bugs and risks
| # | Issue | Impact |
|---|---|---|
| 1 | **Single copy of data on a laptop**, no backups | Disk loss = all history lost |
| 2 | **Mac sleep skips hourly jobs** (6 of 17 snapshot hours missing) | Gaps in the time series. dbt spreads deltas across gaps, but hourly resolution is lost |
| 3 | Postgres password falls back to a dev default in `docker-compose.yml` (4 places) | Safe locally (127.0.0.1 only). Must come from Ansible Vault on the server, with the default removed |
| 4 | Soft 404 on unknown topic pages (HTTP 200) | SEO; fix in P4.6 |
| 5 | Stale `connector_runs` row (id 91) stuck in `running` | Cosmetic. No cleanup of unfinished runs on worker start |
| 6 | Waitlist rate limit is in memory | Resets on API restart; fine for one process, not for several |
| 7 | Breakout videos skip channels whose subscriber count isn't known yet | Some breakouts appear late |
| 8 | Video thumbnails (served by YouTube) often show creators' GTA VI artwork | Our own design uses no Rockstar art; owner to decide whether to show thumbnails |
